1. 개요

글레이즈(GLAZE) "놀란" 드라마 릴스 콘테스트 프로모션 랜딩. 빌드 도구 없는 단일 index.html 정적 페이지로, CSS/JS 전부 인라인이다. 외부 의존성은 Pretendard 폰트 CDN(jsdelivr) 하나뿐이다.

  • 로컬 실행: index.html을 브라우저로 열면 끝 (서버 불필요)
  • 배포: GitHub Pages, main 브랜치 루트 (.nojekyll 포함)

2. 뷰포트 전략 (중요)

<meta name="viewport" content="width=375" />

375px 고정 캔버스를 기기 폭에 맞게 브라우저가 통째로 스케일한다. 모든 좌표가 피그마 375 기준 px 그대로이고, 미디어쿼리가 없다. 이 전제 때문에:

  • 히어로 헤드라인은 <img>가 아닌 인라인 SVG다 — <img>는 확대 전 해상도로 래스터화된 뒤 늘어나 뭉개진다.
  • 태블릿/데스크톱에서는 페이지가 크게 확대된다(의도된 모바일 전용 설계).
  • 반응형 개편 시 이 메타태그부터 손대야 하며, 절대좌표 레이아웃 전체가 영향을 받는다.

5. 인터랙션 명세 요약

  • 히어로 영상: 루프 없이 1회 재생 후 마지막 프레임 홀드 (hero_video_hold.mp4).
  • 스크롤 어피어: 그룹 상단이 뷰포트 하단 30% 지점을 넘으면 그룹 내 .reveal이 --d 스태거로 blur-in. 새로고침 스크롤 복원 시 이미 지나친 그룹은 즉시 표시.
  • 참여 방법: 1번 카드가 마크업에서 기본 열림(class="… open" + aria-expanded="true"). 데모는 화면에 보일 때만 재생. 한 사이클 완주 시 다음 카드로 자동 진행(자동 투어), 3번에서 종료.
  • 모션 접근성: prefers-reduced-motion: reduce에서 .reveal 애니메이션 비활성.

6. 백엔드/앱 연동 필요 지점 (현재 전부 프런트 데모)

네트워크 요청이 단 하나도 없다. 실서비스 전 반드시 연결해야 할 것들:
  1. 카운트다운 종료 시각 — TIMER_DEADLINE(≈2019줄). 현재 null이라 진입 시점부터 3시간 22분을 세는 데모 동작. 실제 마감 시각(예: "2026-08-31T23:59:59+09:00")을 넣거나 서버 시간으로 대체할 것.
  2. 참여 플로우 제출 — 릴스 링크(.flow-input)와 원본 파일(input[type=file], video/*,image/*)이 어디로도 전송되지 않는다. 파일은 createObjectURL 로컬 미리보기만. 확인 모달 "네" 클릭 시 완료 화면으로 넘어갈 뿐이다. 업로드 API + 유효성 검사(링크 형식, 파일 용량 제한) 필요.
  3. 앱바 X 버튼(.appbar .close) — 클릭 핸들러가 없다 (플로우 모달 안의 X는 동작함). 웹뷰 닫기 브릿지 연결 필요.
  4. 당첨 카운트 — "0/1", "0/3" 하드코딩. 실데이터라면 API 연동.
  5. 메타/공유 태그 없음 — og:title/og:image/description, favicon 미설정. 프로모션 특성상 공유가 많을 테니 필수.

9. 알려진 제약 / 주의

  • iOS safe-area 미처리 — 홈 인디케이터 영역 env(safe-area-inset-*) 대응 없음. 페이지 끝이 약관이라 실害는 적지만 앱 웹뷰 삽입 시 확인.
  • 데모 타이밍 수정법 — 카드 1·2는 W1/W2 배열(ms)이 진행바 세그먼트 비율과 모션 대기를 겸한다. 배열만 고치면 진행바도 함께 맞춰진다. 카드 3은 개별 demoWait() 값.
  • 아코디언 열림/닫힘은 grid-template-rows 0fr↔1fr 트랜지션. height: auto 트릭 불필요.
  • .reveal과 translateX(-50%) 충돌 금지 — 어피어는 translate 속성, 센터링은 left: calc(50% - …) 방식을 쓴다. 기존 주석 참조.
  • 콘솔 오류 0건, 404 에셋 0건 (2026-08-13 전수 확인).

10. QA 체크리스트

  • 히어로: 영상 1회 재생 후 홀드, 타이머 카운트다운, X/로고 위치
  • 스크롤: 각 섹션 blur-in이 화면 안에서 보이는지
  • 참여 방법: 1번 기본 열림 → 보일 때만 데모 재생 → 자동 투어 1→2→3 → 수동 클릭 시 투어 중단
  • 화면 이탈 시 데모 정지, 복귀 시 처음부터 재생
  • 플로우: 링크 입력 → 다음 → 파일 첨부(미리보기/재선택) → 참여하기 → 확인 모달 → 완료 컨페티 → 확인으로 닫기
  • 뒤로가기(←)/X 버튼 각 단계 동작
  • iPhone SE(소형)·Pro Max(대형) 실기기 스케일 확인
  • prefers-reduced-motion 켠 상태에서 콘텐츠 정상 노출
